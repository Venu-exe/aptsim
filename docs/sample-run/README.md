# Sample execution artifacts

Generated by `scripts/generate_sample_run.sh` (lab-full profile, seeded,
`time_scale=1.0`). Absolute lab paths are replaced with `<LAB>`.

## Full run

`session/`

| File | Contents |
|---|---|
| `events.jsonl` | 115 ordered events, one JSON object per line |
| `timeline.txt` | rendered timeline + stage duration bars |
| `summary.json` | run status, per-stage durations, event/artifact counts |
| `state.json` | completed stages, payload cursor, capabilities, restarts |
| `transform-manifest.json` | per-file keys, original/transformed SHA-256, backups |
| `edits-manifest.json` | marker edit + backup hashes |
| `anti-analysis.json` | benign vs sandbox mock scenario scores |
| `processes.json` | synthetic PID/parent chain |
| `c2-session.json` | loopback endpoint, request count, task statistics |
| `persistence-report.json` | simulated startup artifacts (host untouched) |
| `heartbeat.json` | liveness evidence |

`verify-before-cleanup.json` classifies every transformed file as
`transformed`; `verify-after-cleanup.json` shows `restored`. `cleanup.log`
contains the restore/finalise event stream.

Highlights:

* stage 2 of the payload loads `sample_stage.py` from `<LAB>/plugins`, records
  its SHA-256, then executes the stage hook;
* the sandbox mock scenario scores 140 (threshold 55) and emits
  `evasion.simulated` with `enforcement=log_only`, `effect=none`;
* 6 files are transformed, 1 is marker-edited, 7 are discovered; the `.bin`
  sample is skipped by configuration;
* the C2 session handles 6 tasks: 4 `ok` and 2 `rejected` (path traversal and
  a `shell` task outside the allowlist);
* cleanup restores all 6 transforms and the edit, removes 4 persistence
  artifacts, and passes the baseline integrity check.

## Crash and resume

`resume/`

A second lab was run with `--stop-after s5-fileops`, which exits 3 after
writing an `interrupted` checkpoint. `aptsim resume --cleanup` then:

* emitted `run.resume` and `stage.already_completed` for the five completed
  stages;
* ran only `s6-network`;
* incremented `restarts` to 2 and finished `completed`;
* restored the transformed files during cleanup.

`resume/state.json` and `resume/timeline.txt` show the exact recovery path.

## Reproduce

```bash
./scripts/generate_sample_run.sh
```

To inspect without regenerating, the committed files are plain JSON/JSONL and
can be loaded with `jq` or the queries in `detections/README.md`.
